# Indian medicine database

`india_medicines.csv.gz` maps about 250,000 Indian medicine brand names to their active ingredients. Scrivia uses it to find out what a confirmed medicine contains before Groq writes about it.

It is a trimmed copy (name and composition columns only, duplicates removed) of the **A-Z Medicine Dataset of India** by Shudhanshu Singh, published on Kaggle: https://www.kaggle.com/datasets/shudhanshusingh/az-medicine-dataset-of-india

The original data, and this trimmed copy, are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The data was collected in November 2022, so newer brands are missing and some listed brands may since have been discontinued.
